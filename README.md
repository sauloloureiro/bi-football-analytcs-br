Plataforma de Inteligência e Análise de Futebol

Projeto de engenharia de dados e análise desenvolvido para explorar informações de jogadores, clubes, campeonatos e partidas de futebol.

A solução contempla desde a ingestão e tratamento dos dados, passando pela modelagem e organização da camada analítica, até a disponibilização das informações para análises e dashboards no Power BI.
O projeto também documenta os processos utilizando BPMN, UML, modelagem de dados e arquitetura de software, além do uso de serviços da Microsoft Azure, versionamento no GitHub, SQL e Python.
O objetivo é construir uma plataforma estruturada, escalável e documentada, aplicando na prática conceitos de engenharia de dados, desenvolvimento de software, modelagem e Business Intelligence.
